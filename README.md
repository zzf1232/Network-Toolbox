# 网络工具箱 Windows 下的一站式网络排查工具，纯 PowerShell 实现，双击即可运行，不需要安装 Python、不需要额外 DLL 或第三方程序。面向弱电、网络运维日常排障使用。 ## 文件组成 | 文件 | 说明 |
|---|---|
| NetworkToolbox.ps1 | 主程序，全部功能都在这个脚本里 |
| 启动工具箱.bat | 启动器，负责申请管理员权限并调用主程序 |

两个文件必须放在同一目录下。 ## 运行环境 - Windows 10 / 11（Windows 8 及以上也可，需 PowerShell 5.1） - 部分功能需要管理员权限：改 IP、改 DNS、网络修复、防火墙开关、端口映射、抓包、WiFi 密码读取 - 抓包功能可选装 Wireshark（含 tshark），未安装时自动退回系统自带 netsh trace ## 启动方法 双击 `启动工具箱.bat` 。脚本会检测当前权限，不是管理员时自动弹出 UAC 提权窗口，确认即可。

不要直接双击 `NetworkToolbox.ps1` ，那样不会提权，部分功能会不可用。 ## 功能清单（共 43 项） ### 网络配置 随机换IP、手动设IP、自动获取IP (DHCP)、预设管理、注册轮换模式 ### 网络检测 网络信息、网络健康检查、网络诊断、网络修复、Ping测试、路由追踪、端口扫描、主机发现(ARP)、会话数统计、路由表 ### 测速与流量 外网测速、内网测速、测速记录曲线、谁在偷流量 ### DNS 与网络服务 DNS切换、智能DNS选优、查询公网IP、DHCP检测 ### 无线与安全 WiFi扫描、WiFi已保存密码、防火墙配置、IP冲突检测、环路检测 ### 工程工具 摄像头扫描、局域网扫描、网络唤醒(WOL)、串口工具、子网计算器、子网划分(等分)、MAC厂商查询 ### 运维工具 端口映射、抓包分析、运维命令库、弱电计算、AI运维助手、远程工具/设备清单 ### 其他 电池/UPS状态、WiFi热点 ## 运行后生成的文件 | 文件/目录 | 用途 |
|---|---|
| presets.json | 预设 IP 方案，首次保存预设时生成 |
| speed-history.csv | 测速历史记录 |
| %TEMP%\NetworkToolboxCaptures | 抓包文件，不写在程序目录 |

删除这些文件不影响程序启动，只是会丢失历史记录。 ## 已知限制 - 抓包：未安装 Wireshark 时使用 netsh trace，输出 ETL 文件，协议解析能力弱于 Wireshark；安装后会自动调用 tshark，可列出数据包与协议统计。 - 摄像头：只做在线探测、端口扫描与厂商识别。预览、改密码、升级固件需要厂商 SDK 和登录凭据，本工具不提供。 - UPS：只读取 Windows 上报的电池信息，笔记本电池也会被列出。串口或网卡型 UPS 需使用厂商软件。 - AI 运维助手为本地关键词规则库，不联网，不调用外部模型，回答范围限于内置的 10 类常见场景。 - 端口映射依赖系统 IP Helper 服务，服务被禁用时规则不生效。 - 串口工具需要 USB 转串口/485 转换器及对应驱动。 ## 常见问题 **双击 bat 后闪一下就没了** 检查两个文件是否在同一目录，文件名是否被改动。 **提示不是管理员权限** 通过 `启动工具箱.bat` 启动，或右键 PowerShell 选择“以管理员身份运行”。 **改 IP 后 IP 没变** 目标 IP 可能已被占用，或被组策略/安全软件限制，先确认网段空闲地址。 **中文显示乱码** `NetworkToolbox.ps1` 必须保存为 UTF-8 带 BOM， `启动工具箱.bat` 必须保存为 GBK（936）。用编辑器另存时注意编码。 **公网 IP 查不到** 本机网络限制或接口临时不可用，工具会依次尝试多个来源，全部失败则显示失败。 ## 免责声明 端口扫描、主机发现、摄像头扫描等功能仅限本机及已获授权的内网使用。请勿对未授权网络进行扫描。使用者需自行承担由此产生的责任。
